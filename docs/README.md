# Discourse Docs Index

This index separates current agent-facing guidance from broader reference docs.
When in doubt, prefer the narrowest current document for the task instead of
loading every doc in this directory.

## Agent-facing docs

- `AGENTS.md`: canonical repo-wide coding and testing instructions.
- `migrations/AGENTS.md`: canonical instructions for migration tooling work.
- `docs/talbotoc-import.md`: current TalbotOC importer and operational runbook.

## Reference docs

- `docs/INSTALL.md`, `docs/INSTALL-cloud.md`, and `docs/INSTALL-email.md`:
  installation references.
- `docs/TESTING.md`: broad testing reference.
- `docs/SECURITY.md`: security policy and reporting reference.
- `docs/developer-guides/`: broad developer guides. Use specific pages as
  needed; do not treat the whole tree as required agent context.

## Archived notes

Archived docs are preserved for audit/history and should not be treated as
current operating instructions unless a newer runbook links to a specific
section.

- `docs/archive/talbotoc-next-stage-migration-2026-05.md`: historical TalbotOC
  migration-stage notes and dated validation results.
